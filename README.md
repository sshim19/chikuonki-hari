# 蓄音機の針

左の指でハンドルを一定の速さで回し、右の指で針を下ろしたり上げたりして、今日の盤を鳴らすゲームです。同じ日は、だれが遊んでも同じ盤です。携帯は横向きで、両手で遊びます。

## 遊び方

1. 画面を横向きにして、「かける」を押します。制限時間は75秒です。
2. 左の指でハンドルを右回りに回し、右の指で針を動かします。マウスなら、片方ずつ動かすことができます。
3. 速さが安定しているときだけ、音の高さと速さが合います。ぜんまいは少しずつ落ちるので、回し続けます。曲の頭で針をそっと落とし、傷や終わりの前で上げます。
4. 22秒を過ぎれば「止める」で早めに確定しても構いません。今日の曲をすべて満たしたら、22秒前でも確定します。時間が来ると、そこまでの響きで終わります。盤を深く傷めたときは、その瞬間に終わります。

最高記録と、その日の最高記録は、この端末に保存されます。0点は記録しません。

終了画面の X と LINE のボタンから、いまの得点をそれぞれの投稿画面で共有できます。

## 開き方

ビルドは不要です。フォルダをウェブサーバーで公開するか、手元では次のように開きます。

```bash
python3 -m http.server
```

ブラウザで `http://localhost:8000/` を開いてください。`file://` では動きません。
