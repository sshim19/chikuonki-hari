# 蓄音機の針

左の親指でハンドルを一定の速さで右回りに回し、右の親指で針を下ろしたり上げたりして、今日の盤を鳴らすゲームです。同じ日は、盤の傷や溝の配置はだれが遊んでも同じです。流れる曲は、遊ぶたびに17曲のなかから選ばれます。携帯は横向きで、両手で遊びます。

## 遊び方

1. 画面を横向きにして、「かける」を押します。制限時間は75秒です。
2. 左の親指でハンドルのまわりを右回りに回し続けます。右の親指は、針が上がっているあいだ左右にずらして位置を決め、下へゆっくりずらすと針が盤に降ります。マウスなら、片方ずつ動かすことができます。
3. 速さが安定しているときだけ、曲の高さと速さが合います。巻きが少しずつ弱まるので、回し続けます。強く落とすと盤に傷がつきます。曲の頭で針をそっと下ろし、傷や終わりの前で上げます。
4. 22秒を過ぎれば「止める」で早めに確定しても構いません。この盤の曲をすべて満たしたら、22秒前でも確定します。時間が来ると、そこまでの響きで終わります。盤を深く傷めたときは、その瞬間に終わります。

盤には、このゲームのために作った短い曲が17曲（ワルツや行進曲、J-POP、ロック、ジャズ、ボサノバ、演歌、ゲーム音楽など）あり、遊ぶたびにそのうち3〜5曲が重ならないように選ばれて刻まれます。針が溝に乗っているあいだだけ曲が流れ、回すのが遅いと曲も低く遅くなり、針が跳ねると先へ飛びます。いまの曲名は蓄音機の正面の札に出ます。

最高記録と、その日の最高記録は、この端末に保存されます。0点は記録しません。

終了画面の X と LINE のボタンから、いまの得点をそれぞれの投稿画面で共有できます。

## 開き方

ビルドは不要です。フォルダをウェブサーバーで公開するか、手元では次のように開きます。

```bash
python3 -m http.server
```

ブラウザで `http://localhost:8000/` を開いてください。`file://` では動きません。
